MASON ELIA — Premium Gastrobar & Hospitality Demo
VGES Online Websites (Project 02)

1. ΕΠΙΣΚΟΠΗΣΗ ΕΡΓΟΥ
------------------
Το παρόν demo αποτελεί σχεδιαστικό πρωτότυπο υψηλής αισθητικής για gastrobar / restaurant, προσαρμοσμένο για το portfolio του VGES Online Websites.
Βασισμένο στο ελεύθερο template Gusto της uiCookies, πλήρως ανασχεδιασμένο με ελληνικό περιεχόμενο, αυτόνομη τυπογραφία, γαστρονομική ταυτότητα και διαδραστικότητα χωρίς εξωτερικές εξαρτήσεις ή build step.

2. ΤΑΥΤΟΤΗΤΑ & DESIGN SYSTEM
----------------------------
• Παλέτα:
  - Spruce Dark:    #172B25 (Κύριο σκούρο φόντο, header, footer)
  - Pine Surface:   #22362D (Κάρτες και ανυψωμένες επιφάνειες)
  - Brass Saffron:  #E8A13C (Χρυσές πινελιές, κανόνες, ενεργά tabs)
  - Paprika Accent: #B44C32 (Terracotta κόκκινο, πρωτεύοντα CTAs)
  - Bone Light:     #F3EBDD (Θερμό ιβουάρ για ανοιχτές ενότητες)
  - Sage Text:      #5E6B60 (Δευτερεύον απαλό κείμενο)
• Τυπογραφία:
  - Τίτλοι / Wordmark: Georgia, "Times New Roman", serif (με webfont Fraunces fallback)
  - Σώμα κειμένου / UI: Arial, sans-serif (με webfont Hanken Grotesk fallback)

3. ΔΟΜΗ ΕΝΟΤΗΤΩΝ (SINGLE-PAGE)
------------------------------
• #top: Ατμοσφαιρικό hero με τίτλο, CTAs και highlights
• #about: Η φιλοσοφία του gastrobar, split layout με φωτογραφία και stats
• #menu: Ενδεικτικός κατάλογος 4 κατηγοριών (Μικρά πιάτα, Κυρίως, Γλυκό, Ποτά)
• #signature: Δύο μεγάλα editorial χαρακτηριστικά (Sharing & Βραδινή ατμόσφαιρα)
• #gallery: 6 φωτογραφίες με πλήρως προσβάσιμο lightbox
• #faq: 3 διευκρινιστικές ερωτήσεις για τη φύση του demo
• #contact: Δοκιμαστική φόρμα ενδιαφέροντος επίσκεψης (client-side demo mode)
• Footer: Disclaimer, εσωτερικά links, τεχνικές προδιαγραφές και credits

4. ΤΟΠΙΚΗ ΠΡΟΕΠΙΣΚΟΠΗΣΗ (LOCAL PREVIEW)
---------------------------------------
Μπορείτε να εκτελέσετε έναν απλό HTTP static server μέσα στον φάκελο site/:
  python -m http.server 8080
ή με Node:
  npx serve .
ή ανοίγοντας απευθείας το index.html σε οποιονδήποτε σύγχρονο browser.
