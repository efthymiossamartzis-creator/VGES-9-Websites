# 05 — ARETI MEDICAL

Κατηγορία: Medical Practice / Healthcare  
Κατάσταση: demo/concept προς υλοποίηση, όχι πραγματικός πελάτης. Έρευνα 23/10/2026.

## Σκοπός και κοινό

Επισκέπτες που χρειάζονται απλή ενημέρωση για τη δομή ενός ιατρείου και τη διαδικασία επίσκεψης.

Reassuring professional healthcare: λευκές επιφάνειες, πράσινο πετρόλ, σαφής πληροφοριακή ιεραρχία και ήρεμος ρυθμός.

## Βάση

uiCookies Vitals — https://uicookies.com/downloads/vitals/

## Περιεχόμενο και εμπειρία

- Κύριο μήνυμα: Η φροντίδα ξεκινά με σαφή ενημέρωση.
- Ενότητες φροντίδας → #services | Προσέγγιση → #about | Επίσκεψη → #visit | Ερωτήσεις → #faq | Επικοινωνία → #contact
- Native FAQ, anchor navigation και φόρμα αποκλειστικά ονόματος/email/γενικής κατηγορίας. Όχι συμπτώματα, attachments ή πεδίο reason for visit.
- Οι ενδεικτικές κατηγορίες δεν συνιστούν επιβεβαιωμένες υπηρεσίες ή ειδικότητες.

## Τι παραδίδεται τώρα

Brief, τεκμηριωμένη επιλογή, πλήρες αυτοτελές Antigravity prompt, asset και deployment checklists. Δεν παραδίδεται υλοποιημένο website, δοκιμασμένο ZIP ή ενεργή φόρμα.

## Έναρξη

1. Διάβασε TEMPLATE-RESEARCH.md και ακολούθησε το επίσημο download page.
2. Αποσυμπίεσε το template σε νέο αποκλειστικό workspace αυτού του project.
3. Δώσε στο Antigravity ολόκληρο το ANTIGRAVITY-PROMPT.md μαζί με τα σωστά αρχεία.
4. Έλεγξε το αποτέλεσμα πριν από χειροκίνητο repository/deployment.
