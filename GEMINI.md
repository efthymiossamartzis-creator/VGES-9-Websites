# Antigravity Workspace Configuration & Rules
# VGES ONLINE WEBSITES — MASTER WORKSPACE

This workspace contains 9 independent website demo projects for VGES Online Websites.

## Critical Behavioral Rules for Antigravity

1. **One Project at a Time:** Work ONLY on the single project folder requested by the user. Do not touch or modify the other 8 folders.
2. **Project Isolation:** Each project (`01-Aurelio-Barbershop`, `02-Mason-Elia`, etc.) has its own independent HTML, CSS, JS, and assets inside its directory. Never share assets across folders.
3. **uiCookies Free Templates Only:** Only use free templates from uiCookies. No MotionSites.
4. **Preserve Existing Work:** Never delete, move, or overwrite existing user files without explicit user confirmation.
5. **Mason Elia Starter:** `02-Mason-Elia/` uses uiCookies Gusto with the pre-configured starter files in `02-Mason-Elia/site/`.
6. **No Auto Git/Deploy:** Never run git commits, pushes, or deployments unless the user explicitly instructs to do so.
7. **Do Not Touch Core Systems:** Never touch the main VGES Online Studio repository or published sites (`vgesonline.pages.dev`).
8. **Documentation:** Keep `MASTER-PROJECTS.md` updated as progress is made on projects.
9. **Standards:** Prioritize fast delivery, premium design, responsive layouts, clean vanilla code, and easy static deployment.

For detailed guidelines, see [WORKSPACE-GUIDELINES.md](./WORKSPACE-GUIDELINES.md) and [MASTER-PROJECTS.md](./MASTER-PROJECTS.md).
