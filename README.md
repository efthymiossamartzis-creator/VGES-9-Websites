- **01-WORKFLOW-AND-ORDER.md**: διαδικασία και σειρά υλοποίησης.
- **LICENSE-AND-ASSETS.md**: πηγές δικαιωμάτων και εκκρεμότητες.

Τα 9 prompts είναι ανεξάρτητα και πλήρη. Δώσε το αντίστοιχο prompt μαζί με τα σωστά αρχεία στο Antigravity. Για Aurelio προηγούνται τα υπάρχοντα αρχεία.

Δεν περιλαμβάνονται ZIP templates, κατασκευασμένα websites ή assets. Οι επίσημες ροές download ζητούν επιβεβαίωση email. Η ύπαρξη σελίδας λήψης ελέγχθηκε, όχι τα τελικά archive bytes. Mobile QA, πλήρης έλεγχος λειτουργιών και άδειες αρχείων παραμένουν μέρος της υλοποίησης.
