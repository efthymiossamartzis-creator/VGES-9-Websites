# Template → Antigravity → Έλεγχος → GitHub Desktop → Cloudflare Pages

## Επαναχρησιμοποιήσιμη διαδικασία

1. **Template:** άνοιγμα του TEMPLATE-RESEARCH.md, λήψη μόνο από την επίσημη σελίδα και έλεγχος ZIP/README/LICENSE. Το download απαιτεί επιβεβαίωση email· κανένα προσωπικό confirmation link δεν αποθηκεύεται σε δημόσιο repo. Για Aurelio χρησιμοποιείται η υπάρχουσα εργασία.
2. **Workspace:** ένας φάκελος ανά project. Ανέπαφο αρχικό ZIP τοπικά εκτός `site/`. Καμία επέμβαση στο Studio ή στο κεντρικό Websites portfolio.
3. **Antigravity:** προσθήκη των σωστών αρχείων, επικόλληση ολόκληρου ANTIGRAVITY-PROMPT.md. Το prompt περιέχει όλες τις ενότητες A–L και δεν απαιτεί προηγούμενο chat.
4. **Έλεγχος:** πραγματική τοπική HTTP προεπισκόπηση, desktop/tablet/mobile, interactions, links, assets, console, φόρμα μόνο ως demo. Διόρθωση FAIL πριν προχωρήσουμε. Τα NOT RUN παραμένουν ρητές εκκρεμότητες.
5. **GitHub Desktop — αργότερα, από τον χρήστη:** ξεχωριστό repository, έλεγχος diff, αποκλεισμός ZIP/secrets/μη αδειοδοτημένων assets. Commit/publish μόνο αφού εγκριθεί το αποτέλεσμα· τώρα δεν έγινε τίποτε από αυτά.
6. **Cloudflare Pages — αργότερα:** ξεχωριστό project ανά demo. Static hosting χωρίς απαραίτητο build, publish folder `site/` ή αντίστοιχη πραγματική ρίζα. Πρώτα preview και πραγματικός έλεγχος του URL. Οι ακριβείς ρυθμίσεις dashboard επιβεβαιώνονται τότε.
7. **Μετά το preview:** ορισμός σωστών OG/canonical URLs, social image και λειτουργικός έλεγχος όλων των routes. Τα demo παραμένουν ορατά ως concepts. Η noindex πολιτική αλλάζει μόνο συνειδητά.
8. **Portfolio — ξεχωριστή εργασία:** σύνδεση των πραγματικά ελεγμένων demos με σωστά names/categories και διάκριση προσαρμογής template. Δεν αλλάζει στην παρούσα φάση.
