## Πρακτική εφαρμογή

- Κρατάμε ξεχωριστή καταγραφή προέλευσης και αλλαγών.
- Αφαιρούμε demo φωτογραφίες και εξωτερικά image hotlinks πριν τη δημοσίευση.
- Για κάθε νέα εικόνα καταγράφουμε ακριβές source URL, δημιουργό, άδεια, ημερομηνία, αποδεικτικό και τυχόν περιορισμούς χρήσης προσώπων/σημάτων.
- Κάθε SVG/icon που δεν δημιουργήθηκε ειδικά για το site χρειάζεται τεκμηριωμένη άδεια. Αν λείπει, το αντικαθιστούμε με απλό ιδιόκτητο γεωμετρικό SVG.
- Ελέγχουμε version και notices του πραγματικού Bootstrap bundle μετά τη λήψη. Διατηρούμε υποχρεωτικά notices των dependencies.
- Οι προτεινόμενες system font stacks χρησιμοποιούν εγκατεστημένες γραμματοσειρές, δεν διανέμουν font files. Webfont επιτρέπεται μόνο αφού ελεγχθεί η άδεια και η υποστήριξη ελληνικών.
- Portfolio wording: «Προσαρμογή και υλοποίηση demo πάνω σε uiCookies [template]», όχι ισχυρισμός σχεδιασμού του αρχικού template από μηδενική βάση.
- Το πακέτο περιέχει δικά μας briefs/prompts/checklists και links προς τον δημιουργό, όχι αντίγραφα templates.
